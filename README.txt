# AyanClubTrade Referral Website

This package is a front-end demo for a referral/rewards website.

Included:
- Landing page
- Signup/login demo
- Unique referral-code generation
- Referral dashboard preview
- Admin demo page
- Responsive mobile design

Important:
This demo uses browser localStorage only. It does NOT provide real authentication, a real database, payment processing, KYC, or verified referral tracking.

For a production website, add:
1. HTTPS + secure authentication
2. Backend/API
3. Database
4. Server-side referral attribution
5. Admin authentication
6. Reward verification and payout rules
7. Privacy Policy, Terms, and applicable legal/tax compliance

Do not advertise guaranteed income. Publish clear eligibility and reward conditions.
